# Case-2.Superstore-analysis

## Этап 1. - Data Quality

9 994 строки X 21 признак, 2014–2017. Пропусков и полных дубликатов нет.
Приведены типы (даты, `Postal Code`), проверена логика доставки
(`Ship Date >= Order Date`, 0 нарушений) и целостность заказов
(один `Order ID` - один клиент и адрес). Выбросы в `Sales` и отрицательный
`Profit` оставлены — отражают реальные промо-кейсы.
Очищенный датасет: `data/superstore_clean.parquet`.
      
## Этап 2. - Overview / KPI

Период 2014–2017. Выручка ~ **2.29 млн**, прибыль ~ **286 тыс.**,
маржа ≈ **12.5%**, средний чек ~ **458**, средняя скидка ~ **15.6%**.
Выручка растёт ежегодно, но маржа снижается — растущая скидочная нагрузка.
Пик продаж — сентябрь–декабрь. Technology — драйвер прибыли,
Furniture — низкая маржа (Tables/Bookcases убыточны).
